# 🎃 Halloween Weather & Visitor Analysis Dashboard

An interactive **Halloween Weather & Visitor Analysis Dashboard** created using Tableau to explore historical rainfall patterns, visitor variations, and visitor forecasting.

🔗 **View the Interactive Dashboard on Tableau Public:**  
https://public.tableau.com/app/profile/gowri.shankari1922/viz/hallowenWeatherDashboard_17897065715600/Dashboard2?publish=yes


## 📌 Project Overview

This project presents an interactive Tableau dashboard designed to analyze historical Halloween-related weather and visitor data.

The dashboard combines multiple visualizations into a single analytical view, allowing users to explore:

- Rainfall trends across years
- Rain events
- Visitor variations
- Visitor forecasting
- Cumulative rainfall
- Rainfall by day of the week

Interactive filters allow users to explore the data by **Year** and **Day of Week**.


## 🎯 Objectives

The main objectives of this dashboard are to:

- Analyze historical rainfall patterns.
- Understand yearly visitor variations.
- Examine rainfall distribution across days of the week.
- Track cumulative rainfall.
- Analyze recorded rain events.
- Visualize historical visitor trends.
- Explore visitor forecasts based on historical data.

## 📊 Dashboard Components

### 🌧️ Halloween Rainfall Trend

A line chart showing rainfall variation across the recorded years.

### ☔ Rain Event by Date

A bar chart showing the number of recorded rain events across different years.

### 👥 Visitor Forecast

A time-series visualization showing historical visitor totals along with a forecast generated in Tableau.

### 📈 Variation by Visitor in Year

A comparison of visitor totals across different years.

### 💧 Cumulative Rainfall

A visualization showing the accumulated rainfall over the analyzed period.

### 📅 Rainfall by Day of Week

A comparison of rainfall across different days of the week.
